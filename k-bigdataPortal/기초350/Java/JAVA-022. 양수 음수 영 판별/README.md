# [JAVA-022] 양수 음수 영 판별

[문제 링크](https://portal.k-bigdata.kr/coding.html?id=JAVA-022) · 입문 · 조건문

## 문제

정수 하나를 입력받으시오. 양수이면 POSITIVE, 음수이면 NEGATIVE, 0이면 ZERO를 출력하시오.

## 입출력 예제 1

입력

```
0
```

출력

```
ZERO
```

## 입출력 예제 2

입력

```
0
```

출력

```
ZERO
```

## 입출력 예제 3

입력

```
-7
```

출력

```
NEGATIVE
```
