# [JAVA-026] 점수의 학점 판별

[문제 링크](https://portal.k-bigdata.kr/coding.html?id=JAVA-026) · 입문 · 조건문

## 문제

점수(0~100)를 입력받으시오. 90점 이상은 A, 80점 이상 90점 미만은 B, 70점 이상 80점 미만은 C, 60점 이상 70점 미만은 D, 60점 미만은 F를 출력하시오.

## 입출력 예제 1

입력

```
85
```

출력

```
B
```

## 입출력 예제 2

입력

```
90
```

출력

```
A
```

## 입출력 예제 3

입력

```
59
```

출력

```
F
```
