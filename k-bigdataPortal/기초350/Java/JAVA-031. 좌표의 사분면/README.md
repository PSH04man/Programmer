# [JAVA-031] 좌표의 사분면

[문제 링크](https://portal.k-bigdata.kr/coding.html?id=JAVA-031) · 입문 · 조건문

## 문제

정수 좌표 x, y(둘 다 0이 아님)를 입력받으시오. 해당 좌표가 위치한 사분면의 번호(1~4)를 출력하시오.

## 입출력 예제 1

입력

```
-3 4
```

출력

```
2
```

## 입출력 예제 2

입력

```
3 -2
```

출력

```
4
```
