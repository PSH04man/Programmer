# [JAVA-032] 월의 날짜 수

[문제 링크](https://portal.k-bigdata.kr/coding.html?id=JAVA-032) · 입문 · 조건문

## 문제

월을 나타내는 정수(1~12)를 입력받으시오. 평년을 기준으로 해당 월의 날짜 수(28, 30 또는 31)를 출력하시오.

## 입출력 예제 1

입력

```
2
```

출력

```
28
```

## 입출력 예제 2

입력

```
4
```

출력

```
30
```
