# [JAVA-033] 할인 금액 계산

[문제 링크](https://portal.k-bigdata.kr/coding.html?id=JAVA-033) · 입문 · 조건문

## 문제

0원 이상의 구매 금액을 입력받으시오. 10000원 이상이면 10%를 할인하고, 그렇지 않으면 할인하지 마시오. 할인액은 정수 나눗셈으로 계산하여 최종 결제 금액을 출력하시오.

## 입출력 예제 1

입력

```
15000
```

출력

```
13500
```

## 입출력 예제 2

입력

```
9999
```

출력

```
9999
```
