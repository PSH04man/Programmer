# [JAVA-035] 월의 계절 구분

[문제 링크](https://portal.k-bigdata.kr/coding.html?id=JAVA-035) · 입문 · 조건문

## 문제

월(1~12)을 입력받으시오. 3~5월은 SPRING, 6~8월은 SUMMER, 9~11월은 FALL, 12월과 1~2월은 WINTER를 출력하시오.

## 입출력 예제 1

입력

```
12
```

출력

```
WINTER
```

## 입출력 예제 2

입력

```
6
```

출력

```
SUMMER
```
