# [LINUX-001] 프로젝트 폴더와 빈 파일 만들기

[문제 링크](https://portal.k-bigdata.kr/coding.html?id=LINUX-001) · 입문 · 파일·디렉터리

## 문제

현재 디렉터리에 project 폴더를 만들고 그 안에 src 폴더를 생성하시오. Vim으로 src 폴더에 빈 main.py 파일을 저장하시오. 마지막으로 생성한 폴더와 파일을 확인하시오.

## 입출력 예제 1

초기 실행 환경

```
student@ubuntu:~/lab$ ls

student@ubuntu:~/lab$ [명령어 입력]
```

예상 실행 결과

```
student@ubuntu:~/lab$ [명령어 입력]
project:
src

project/src:
main.py
```
